# Stack

Tools, software, and resources used to build this portfolio.

## Design

- Figma | figma.com | Interface design
- Framer | framer.com | Prototyping

## Development

- VS Code | code.visualstudio.com | Code editor
- Next.js 15 | nextjs.org | React framework
- Tailwind CSS | tailwindcss.com | Styling
- GitHub | github.com | Version control
- Vercel | vercel.com | Hosting

## Dependencies

- `@phosphor-icons/react` | Icons
- `clsx` + `tailwind-merge` | Utility functions
- `framer-motion` | Animations

## Browser

- Arc | arc.net | Primary browser
